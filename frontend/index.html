Everything in one place

A practical placement toolkit for students

Built around one simple question: how well does this resume match this job, and what should the candidate learn next?

Resume skill extraction

Upload a PDF or DOCX resume. The platform reads the text and detects known technical skills, without any paid AI API.

Transparent match score

See the exact calculation: matching skills divided by required skills. Matched skills are green and missing skills are red.

Skill-gap courses

Every missing skill comes with free learning resources plus ready-made search links for YouTube, Coursera, Udemy and freeCodeCamp.

Application tracking

Follow every application from Pending to Shortlisted, Accepted or Rejected, with the match score saved at application time.

Recruiter workspace

Recruiters can post jobs, search candidates by skills, review match scores and manage applicant statuses from one dashboard.

Secure by design

Passwords are hashed with bcrypt, protected routes use JWT, and resumes are stored privately and downloaded only with authorization.

How it works

From resume to interview in three steps

A straightforward workflow that is easy to explain in a practical examination.

01

Upload your resume

Choose a PDF or DOCX file. The backend extracts text, finds technical skills and stores a private copy of the file.

02

Compare and improve

Browse jobs ranked by match percentage. Review missing skills and use the recommended free resources to learn them.

03

Apply and track

Submit up to ten applications per day, prevent duplicates, and track every recruiter status change in real time.
